# 部署指南

> 分两种场景：**方式一**本机验证打包产物（最快）；**方式二**云服务器 Linux 部署（简历加分项）。

---

## 方式一：本机验证打包产物（最快）

### 后端（已经打好包了）

确认三件事：MySQL 在跑、Redis 在跑（`E:\redis\start-redis.bat`）、MinIO 在跑（`E:\minio\start-minio.bat`）。

然后直接跑 jar（不依赖 Maven）：
```bash
cd backend
java -jar target/secondhand-0.0.1-SNAPSHOT.jar
```

### 前端

```bash
cd frontend
npm run build        # 生成 dist/（生产版静态文件）
npm run preview      # 本地预览 dist（默认 http://localhost:4173）
```

> 注意：`npm run preview` 只用于预览静态文件，接口请求 `/api` 没有代理会失败。
> 要在浏览器完整用起来，前端开发用 `npm run dev`（有代理）；生产请用 Nginx 托管（见方式二）。

---

## 方式二：云服务器 Linux 部署（简历加分项）

### 步骤 0：准备服务器

买一台云服务器（阿里云/腾讯云轻量即可），系统选 Ubuntu 或 CentOS，**安全组放行 80 端口**（Nginx）和 8080（后端，可只对本机开放）。

SSH 登录服务器后装软件（Ubuntu 示例）：
```bash
sudo apt update
sudo apt install -y openjdk-17-jdk nginx mysql-server redis-server
```

> MinIO 也可以用 `wget` 下载单文件版放服务器上跑，或用 Docker。

### 步骤 1：上传并启动后端

**本地打包**（已在阶段 9 验证过）：
```bash
cd backend && mvn package -DskipTests
```

**上传 jar 到服务器**（用 scp，或宝塔/FileZilla 等）：
```bash
scp target/secondhand-0.0.1-SNAPSHOT.jar root@服务器IP:/opt/app/
```

**在服务器建配置文件** `application-local.yml`（⚠️ 这个文件被 gitignore，仓库里没有，必须手动建）。把数据库/Redis/MinIO 的地址改成服务器的：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/campus_secondhand?useUnicode=true&characterEncoding=utf-8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
    username: root
    password: 你的服务器数据库密码
    driver-class-name: com.mysql.cj.jdbc.Driver
minio:
  endpoint: http://服务器IP:9000   # 改成服务器地址
  access-key: minioadmin
  secret-key: minioadmin
  bucket: campus-secondhand
```

**导入数据库脚本**（把 `sql/schema.sql` 也上传后执行）：
```bash
mysql -u root -p < /opt/app/schema.sql
```

**后台启动后端**：
```bash
cd /opt/app
nohup java -jar secondhand-0.0.1-SNAPSHOT.jar \
  --spring.config.additional-location=/opt/app/ > app.log 2>&1 &
```

验证：`curl http://localhost:8080/category/list` 有 JSON 返回即成功。

### 步骤 2：前端打包并上传

```bash
cd frontend && npm run build   # 生成 dist/
scp -r dist root@服务器IP:/var/www/dist/
```

### 步骤 3：配置 Nginx

编辑 `/etc/nginx/sites-available/default`（或新建配置）：
```nginx
server {
    listen 80;
    server_name 你的IP或域名;

    # 前端静态文件
    location / {
        root /var/www/dist;
        index index.html;
        try_files $uri $uri/ /index.html;   # Vue history 模式刷新不 404
    }

    # 后端接口代理（前端请求 /api/xxx -> 后端 /xxx）
    location /api/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

生效配置：
```bash
sudo nginx -t          # 检查配置语法
sudo nginx -s reload   # 重载
```

### 步骤 4：验证

浏览器访问 `http://服务器IP/` → 前端页面；点登录/看列表，接口自动走 Nginx 代理到后端。全通即部署成功！🎉

---

## ⚠️ 部署注意点（踩坑预警）

1. **`application-local.yml` 是 gitignored 的**——服务器上不会自动有，必须手动创建，里面所有地址改成服务器的，密码不能照抄本地。
2. **图片 URL 是绝对地址**：MinIO 返回的 URL 形如 `http://localhost:9000/...`。本地测试产生的旧商品，图片 URL 指向 localhost，在服务器上打不开；部署后用新上传的图片即可（MinIO endpoint 记得配服务器 IP）。
3. **Redis 默认无密码**：务必只监听本机 `bind 127.0.0.1`，否则暴露公网容易被爆破利用。
4. **MySQL 设强密码**，限制远程登录（只用 localhost 即可）。
5. **内存**：jar + MySQL + Redis + MinIO 比较吃内存，服务器建议 2G 起步；内存紧张可以先不装 MinIO 本地，换便宜的对象存储或压缩图片。
6. **后端端口**：8080 不必对公网开放，Nginx 在本机代理即可，更安全。
